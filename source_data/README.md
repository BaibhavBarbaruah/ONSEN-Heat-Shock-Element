# Compact figure source data

This directory contains compact source tables used for figure-level verification without duplicating the full final supplementary workbooks.

- `Figure4A_direct_LTR_methylation_summary.tsv`: direct element/copy-level ONSEN versus non-ONSEN LTR-retrotransposon methylation statistics in final Table S8A.
- `Figure4C_direct_LTR_HSF_summary.tsv`: sample sizes, medians and significance reporting used for the direct element-level HSF-density comparison in Fig. 4C.
- `Figure7_variant_metrics.tsv`: mismatch counts and 49-bp sequence identity used for Fig. 7C.
- `Figure7_logo_model_metadata.csv`: exact representative JASPAR models used for Fig. 7D.

All final supplementary-table worksheets, including full global gene and TE differential-expression results, are mirrored under `../supplementary_table_source/`. Large raw/reference inputs and externally generated processed intermediates are documented in `../INPUT_PROVENANCE.tsv`.
