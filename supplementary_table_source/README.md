# Final supplementary-table source sheets

This directory contains tab-separated exports of every worksheet in the authoritative journal-facing `Table_S1.xlsx` through `Table_S13.xlsx` workbooks at the repository root.

The filenames use the final Biology Open numbering. They do **not** use the obsolete pre-final numbering, and there is no final Table S14. The AP2/ERF-only workbook from the earlier revision is not part of this package.

`SOURCE_SHEET_MANIFEST.tsv` maps each workbook to its worksheet names and dimensions. Formula cells are exported using the calculated values stored in the corresponding final workbook. The Excel workbooks remain the submission artifacts; these TSV files provide plain-text, machine-readable mirrors for inspection and version control.
